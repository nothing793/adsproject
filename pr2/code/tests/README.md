# 正确性测试

`test.c` 是不依赖第三方库的 C99 测试程序。请勿使用 `-DNDEBUG` 编译测试，因为断言同时承担验证作用。

`run_tests.py` 使用 Python 标准库调用 GCC，启用 `-Werror` 构建三个入口，执行 C 测试及 CLI 回归，核对基准程序的查询数限制和固定种子复现结果，并保存 `validation.log`。运行示例：`python tests/run_tests.py --output /path/to/local-validation`。

- 对两种堆执行 30000 次操作，与线性扫描的最小值比较，每步审计 Fibonacci 堆环结构、父指针、度数、标记及二叉堆位置映射。
- 显式制造级联切割，检查第一次丢孩子的标记与第二次丢孩子后的切割；覆盖提前停止后复用、空堆与清空。
- 验证 DIMACS 错误输入、重边、零权边、自环、不连通、编号越界和 64 位距离边界。
- 在 100 张小型有向图上用独立 Floyd–Warshall 对拍全部起终点，同时检查返回路径，分别验证完整单源和目标出堆提前终止。

在 `code/` 下执行 `make test`，或按上一级 README 的 GCC 命令编译。运行时会在当前目录临时创建并删除 `test_graph.tmp`，因此请在可写目录运行，且不要并行执行多个测试进程。

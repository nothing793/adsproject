# Project 3 报告

- `report.md`：中文实验报告，包含问题描述、算法伪代码、正确性证明、测试表和复杂度推导。
- `report.pdf`：由同一 Markdown 文稿导出的定稿。
- `report.html`：已完成公式排版和代码高亮的离线阅读版本，配图位于同目录。
- `sample_solution.png`：根据样例 1 的实际输出绘制的恢复布局。
- `runtime.png`：从测试记录绘制的进程墙钟时间曲线。
- `assets/`：图表、报告和 PDF 的生成工具，使用方法见该目录的 `README.md`。

逐例输入、输出、统计和校验清单收录在 `../testresult/validation-20261020.zip`。报告中的测试表与图表均由该压缩包中的记录生成。

变量下标、约束及复杂度推导使用 LaTeX 语法；PDF 中公式为矢量字形，正文约 11 pt、独立公式约 11.5 pt，保留正常上下标比例。文字统一为深色，正文、标题、表格和图注采用同一中文字族；代码使用单色高亮，以字重区分关键词。

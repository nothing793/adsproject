# 验证程序

使用 Python 标准库与 gcc，不依赖外部 SAT 求解器。在 `pr3` 目录执行：

```bash
python code/tests/run_tests.py --output testresult/run
```

`--cc` 可指定编译器路径。测试在输出目录生成临时可执行文件，以及输入、输出、日志、完整 CSV 和环境摘要；这些散文件不提交到 Git。最终测试材料见 `../../testresult/validation-20261020.zip`。

| 文件 | 内容 |
| --- | --- |
| `run_tests.py` | 编译、独立选边穷举、逐方向几何检查、固定种子规模试验、非法输入及 SAT 核心对拍 |
| `sat_driver.c` | SAT 批处理测试入口，每个公式为变量数、子句数及以 0 结束的带符号文字列表 |

验证范围为 1,804 个花园用例、14 个非法输入、2 个接口错误路径及 3,004 个 SAT 核心公式，共 4,824 项，全部通过。花园测试包括题目三个样例、12 个专项用例、2×2 的全部 625 个 0..4 度数组合、3×3 的全部 512 个 0/1 组合、600 个随机小用例、48 个已知布局反推输入、3 个满网格二度用例及一个大规模不平衡分量。接口错误路径检查未知命令行参数和标准输出只读句柄，后者验证缓冲刷新失败能够被报告。

随机种子固定为 20261020。小规模可行性通过直接选边搜索确定，独立于 C 程序的 CNF 构造。SAT 随机公式最多 10 变量，枚举全部真值赋值并逐条检查返回模型；7 鸽 6 孔用例覆盖学习、回溯与重启。

每个花园用例有 30 秒测试超时，SAT 批处理为 120 秒；超时会使测试失败。C 求解器本身不把耗时当作无解条件。输入和输出以 UTF-8 保存，适配 Windows 中文诊断。墙钟时间包含进程启动和输入输出，规模表每行汇总三份同分布而不同的输入。
